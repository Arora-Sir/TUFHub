Welcome to TUFHub
Step 1: Connect your GitHub Account

Generate a GitHub Personal Access Token (PAT) with repo scope to allow TUFHub to automatically commit your solved problems.

  1. Click here to generate token on GitHub (Pre-configured with repo permissions)
  2. Set Expiration to No expiration (or your preferred duration).
  3. Scroll down and click Generate token, then copy the generated token.

Connect using a registered GitHub OAuth Application.

💡 Note: PAT (Personal Access Token) is recommended for most users. OAuth requires you to register and manage your own GitHub OAuth App credentials.

⚡ Automatic 1-Click Registration: The link below opens GitHub with Application Name, Homepage URL, and Callback URL pre-filled automatically for your browser!
