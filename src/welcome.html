🔗 Welcome to TUFHub
Step 1: Connect your GitHub Account

Generate a GitHub Personal Access Token (PAT) with repo scope to allow TUFHub to automatically commit your solved problems.

  1. Click here to generate token on GitHub (Pre-configured with repo permissions)
  2. Set Expiration to No expiration (or your preferred duration).
  3. Scroll down and click Generate token, then copy the generated token.

Connect using a registered GitHub OAuth Application.

  1. Click here to register a new OAuth App on GitHub (Pre-fills name & callback URL automatically)
  2. Set Application Name to TUFHub and Homepage URL to https://github.com/.
  3. Set Authorization callback URL to your Chrome Extension redirect URI below:
Homepage: https://github.com/
Callback: https://...chromiumapp.org/
Step 2: Create Solutions Repository

Set up a dedicated repository on your GitHub account to store your code and problem READMEs.

🎉 You're All Set!

Your solutions will now auto-sync every time you get an Accepted verdict on TUF+.

Go to TUF+ View Repository
